# x-brain

Joshua Renfro's X bookmarks, compiled into an Obsidian knowledge base by an LLM (the "LLM Wiki" pattern described in [[wiki/concepts/llm-knowledge-bases]]).

- `raw/` — one immutable note per bookmark · `wiki/` — compiled concepts, entities, digests · `outputs/` — filed answers
- Start at [[index]] · change history in [[log]] · browse bookmarks in `bookmarks.base` · concept map in `maps/concept-map.canvas`
- Agents: read `CLAUDE.md` / `AGENTS.md` first. Obsidian conventions come from the vendored `.skills/obsidian-skills/` (MIT, kepano).

Open the folder as a vault in Obsidian. Local-only for now (no remote configured).
