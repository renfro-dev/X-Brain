# Agentic Org Maturity (AI Transformation Ladder)

[[wiki/entities/people/mark-ajzenstadt|Mark Ajzenstadt]] ([[raw/2026-10-24-mardehaym-2113991017506414930|@mardehaym]]) lays out seven steps "to go from tool adoption to agentic org": "Most companies sit on step one, shopping for step seven technology. They need step four discipline."

1. **Tool adoption** — humans run each AI tool; "Developer closes the lid, automations die."
2. **Context layer** — knowledge graphs per department behind API gateways, keeping agents from "hallucinating across departmental boundaries."
3. **Harness engineering** — eval criteria, routing, quality gates before choosing a model → [[wiki/concepts/agent-harness-engineering|Agent harness engineering]]
4. **Go headless** — automations hosted off-laptop, firing on schedules/conditions → [[wiki/concepts/always-on-agent-infrastructure|Always-on agents]]
5. **Governance** — RBAC on knowledge structures; TTL on every agent ("Dead agents are tech debt with active API keys"); past 100 tools, lifecycle management; retire anything idle 90 days or below eval thresholds.
6. **Agent-to-agent** — handoffs with an LLM quality gate → [[wiki/concepts/multi-agent-orchestration|Multi-agent orchestration]]
7. **Step functions** — orchestrated workflows; "Agents handle volume. Humans handle exceptions."

Note: the thread ends with sales CTAs (discovery call, a Limestone Digital "AI Foundation" guide, case studies) — it is marketing content.
