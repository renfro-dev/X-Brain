# Digest — Agent harnesses & agentic orgs

- **Harness > model**: [[raw/2026-10-23-hayatomaruu-2113719510985269442|@hayatomaruu]] and [[raw/2026-10-24-mardehaym-2113991017506414930|@mardehaym]] both argue reliability/IP lives in the harness (loops, state, gates, recovery), with the model a swappable commodity.
- **Concrete setup**: the quoted @beamnxw article's 7 Claude Code layers (CLAUDE.md, skill, MCP, permissions/hooks, evidence reviewer, effort, `/goal`).
- **Org ladder**: tool adoption → context layer → harness → headless → governance → agent-to-agent → step functions ([[raw/2026-10-24-mardehaym-2113991017506414930|@mardehaym]]).
- Caveat: both are promotional (salary claim; sales CTAs).
