# morluto/rea (Reverse Engineer Anything)

An open-source MCP toolkit described by [[raw/2026-11-08-monokern-2119446181231067489|@monokern]] (in his quoted article) as connecting AI agents to disassembly engines (Ghidra, Hopper, IDA), JavaScript/Electron analyzers and network inspection. He claims it "crossed 110,000 GitHub stars"; this is unverified and the repo was not checked. The article pairs it with [[wiki/entities/tools/grok-bot|Grok Bot]]'s cloud computer and frames the use as clean-room interoperability, not cracking. Related: [[wiki/entities/tools/model-context-protocol|MCP]], [[wiki/entities/people/monokern|@monokern]].
