# Grok Bot

An agent product described by [[raw/2026-11-06-s4yonnara-2118814330695073907|@s4yonnara]] (quoting his own article) as an AI agent "with its own computer in the cloud": a browser, file system and terminal that keep running while you're away, plus login handoff so you sign in yourself instead of pasting passwords. The same post lists GitHub repos that package Grok Bot agent teams. All details here are the author's claims, including pricing.

Related: [[wiki/concepts/always-on-agent-infrastructure|Always-on agents]], [[wiki/concepts/multi-agent-orchestration|Multi-agent orchestration]].

## Added 2026-11-09

Two more sources describe Grok Bot bots: [[raw/2026-11-08-irongiantXBT-2119484092089762141|@irongiantXBT]] (10 scheduled bots with prompts; a "Grok Swarm" orchestrator; a "company brain" setup with Opus 5.5) and [[raw/2026-11-08-monokern-2119446181231067489|@monokern]] (6 favorite bots, some credited to SpaceXSI staff, bot pages at x.ai/bot/...). All claims are the authors' own. See [[wiki/concepts/agent-bot-catalogs|Agent bot catalogs]].
