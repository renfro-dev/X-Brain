# Model Context Protocol (MCP)

Protocol exposing external tools/data to agents. Harness layer 3, "give the task access to its source material" (e.g. a Notion connection), with unused servers disabled via `/mcp` ([[raw/2026-10-23-hayatomaruu-2113719510985269442|@hayatomaruu]]). [[raw/2026-10-25-danikkk_wqs-2114344135415021632|@danikkk_wqs]] notes MCP + Obsidian's Local REST API are only needed to talk to a running Obsidian app. See [[wiki/concepts/mcp-and-context-management|MCP & context management]].
