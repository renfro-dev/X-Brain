# Claude Opus 5.5

The model targeted by the harness guide quoted in [[raw/2026-10-23-hayatomaruu-2113719510985269442|@hayatomaruu]] ("Make Opus 5.5 Finish Long Tasks"); "Opus 5.5 → Agents → Harness → Loops → Graphs". The guide says Opus 5.5 defaults to `medium` effort unless settings override it. See [[wiki/concepts/agent-harness-engineering|Agent harness engineering]].

## Added 2026-10-31
- Named as the base model in [[raw/2026-10-30-hanakoxbt-2116267647100707095|@hanakoxbt]] (loops & graphs promo) and [[raw/2026-10-27-Grow_withAI-2115062331227226349|@Grow_withAI]] ("Opus 5.5 → Agents → Harnesses → Loops → Graphs").

## Added 2026-11-02
- Cast as the planner and reviewer in [[raw/2026-11-01-damkina7-2116870392300073128|@damkina7]]'s setup, as "just the brain" in [[raw/2026-11-01-hayatomaruu-2117003050090938646|@hayatomaruu]], and as a model you shouldn't prompt directly in [[raw/2026-10-31-LunarResearcher-2116522516915028254|@LunarResearcher]]. See [[wiki/concepts/model-routing|Model routing]].

## Added 2026-11-09

[[raw/2026-11-08-irongiantXBT-2119484092089762141|@irongiantXBT]] claims Opus 5.5 is the "thinker" escalated to for the hardest ~1% of turns, citing 66.4% on terminal-bench 4.0 (unverified). [[raw/2026-11-08-hanakoxbt-2119538190868775268|@hanakoxbt]] opens with "Before you blame Opus 5.5" and argues commands and loops matter more than the model.
