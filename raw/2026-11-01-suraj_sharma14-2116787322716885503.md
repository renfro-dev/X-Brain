Got an AI engineer interview coming up?

These 25 questions come up again and again. Prep them and you'll walk in ready:

• What's the difference between a chatbot and an agent?
• How does an agent decide which tool to use?
• Explain the reasoning loop: think, act, observe, repeat
• When would you use RAG instead of fine-tuning?
• How do embeddings and vector databases work together?
• How do you handle a context window that's too small?
• Short-term vs long-term memory: how would you design both?
• What is MCP and why does it matter?
• Single agent or multi-agent: when do you pick each?
• How does an orchestrator split work between sub-agents?
• How do you stop an agent from looping forever?
• What guardrails would you add before giving it real tools?
• Where should a human approve actions?
• How do you evaluate whether an agent actually works?
• What metrics would you track in production?
• How do you debug an agent that gave a wrong answer?
• How do you reduce hallucinations?
• How do you cut token cost without hurting quality?
• How do you reduce latency in a multi-step agent?
• How would you handle a tool call that fails?
• How do you protect against prompt injection?
• How would you design an agent that books flights?
• How would you design a customer support agent?
• What breaks first when you scale agents to 1M users?
• Tell me about an agent you built and what failed

Most candidates can explain an LLM.
Very few can design a system around one.
